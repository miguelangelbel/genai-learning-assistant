# GenAI Learning Assistant

End-to-end GenAI learning project focused on building and understanding the main components of modern LLM applications.

The project evolves progressively from direct LLM API usage to RAG, LangChain, conversational assistants, agents and fine-tuning.

## Objectives

The main goal is to reinforce and connect concepts related to:

* LLM APIs
* Prompt engineering
* Embeddings
* Semantic similarity
* Vector search
* Retrieval-Augmented Generation (RAG)
* LangChain
* Conversational memory
* FastAPI
* Chat interfaces
* Tool calling and agents
* Fine-tuning
* LLM and RAG evaluation

Core concepts will be implemented manually whenever possible before introducing higher-level frameworks.
